# SGSI
Sistema de Gestión de Solicitudes Internas de la Asamblea Legislativa de Costa Rica


## Descripción General

Este repositorio contiene una versión pública sanitizada de un sistema interno orientado a la gestión de solicitudes, generación de boletas, procesamiento documental, impresión y seguimiento operativo.

## Aviso de Confidencialidad

Componentes sensibles de infraestructura, mecanismos de autenticación, lógica operativa interna, integraciones institucionales y módulos críticos de seguridad fueron removidos o modificados intencionalmente.

Esta versión pública se proporciona únicamente con fines educativos y de demostración profesional.

## Aviso Legal

El software y el código fuente están protegidos conforme a la Ley N.º 6683 de Costa Rica — Ley de Derechos de Autor y Derechos Conexos.

El sistema interno original contiene componentes adicionales protegidos e implementaciones confidenciales que no se incluyen en este repositorio.
